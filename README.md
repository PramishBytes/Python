## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

* **Python 3.x**
* **Jupyter Notebook** or **JupyterLab**

You can install Jupyter using:

```bash
pip install notebook jupyterlab
```

Some scripts may require additional Python packages:

```bash
pip install requests psutil pytube
```

> **Note:** Dependencies may vary depending on the script you want to run.

---

## 📥 Clone the Repository

Clone the repository using Git:

```bash
git clone https://github.com/PramishBytes/Python.git
```

Navigate into the repository:

```bash
cd Python
```

---

## ▶️ Running Python Scripts

Run any Python script using:

```bash
python <script_name>.py
```

For example:

```bash
python intro.py
```

On some systems, you may need to use:

```bash
python3 <script_name>.py
```

---

## 📓 Running Jupyter Notebooks

Start Jupyter Notebook:

```bash
jupyter notebook
```

Or start JupyterLab:

```bash
jupyter lab
```

Then open any `.ipynb` notebook from the browser interface.
